## Short description

Search Xiaohongshu, Douyin, and WeChat Official Accounts.

## Long description

TikHub Search gives Codex a thin, read-only search layer for three important Chinese walled-garden platforms: Xiaohongshu, Douyin, and WeChat Official Account articles. It discovers current TikHub MCP tools, maps common sort and time filters, and returns consistent result lists with source links. Users can optionally expand selected public results into details or comments without turning every search into a large research workflow.

This skills-only plugin does not include a TikHub account, API key, or credit. Users connect TikHub's hosted platform MCP servers or use the guarded REST fallback with their own account.
