# Support

Use GitHub Issues in the public `tikhub-search` repository for reproducible bugs, documentation problems, and feature requests.

Before reporting a problem:

1. Remove API keys, Authorization headers, personal data, and raw search responses.
2. Include the skill version, Codex version, operating system, platform, and whether MCP or REST was used.
3. Include a minimal redacted error and TikHub `request_id` when safe.
4. Confirm whether the issue affects Xiaohongshu, Douyin, WeChat Official Accounts, or more than one platform.

For account, billing, endpoint availability, or upstream platform failures, contact TikHub support.
