# Privacy

Effective date: 2026-08-27

TikHub Search is an instruction-and-script package. It does not operate a hosted service, collect analytics, receive API keys, or transmit search data to the publisher.

When a user connects TikHub or runs the REST fallback, requests go directly from the user's environment to TikHub. TikHub's own privacy terms and data practices apply. Users control local output files and are responsible for access control, retention, deletion, and downstream processing.

The skill searches public surfaces and instructs users not to expose credentials, collect private or deleted material, or retain unnecessary personal data. Ordinary commenters should be anonymized in summaries unless identity is necessary.

Questions or reports can be submitted through the repository's GitHub Issues after the public repository URL is available.
